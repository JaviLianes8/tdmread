# Contributing

Thanks for taking the time. This project keeps a small, predictable shape.

## Setup

```
pip install -r requirements-dev.txt
```

## Before you open a pull request

- Keep public API in `src/tdmread/__init__.py`; internals live in `_`-prefixed modules.
- Add a test for the behaviour you change. Tests inject time, disk and network; they
  never touch the real thing.
- The always-on fixtures in `tests/fixtures/synthetic` are generated by
  `python scripts/make_synthetic_tdm.py`; regenerate them rather than editing them. The NI
  `SineData` samples are never committed: `python scripts/fetch_upstream.py` downloads them
  into `tests/upstream` (checked against `tests/upstream/MANIFEST.json`) and their tests
  skip until then.
- Run `scripts/check.ps1` (format, lint, types, tests) and make sure it passes.
- One logical change per commit, imperative subject line.

Open an issue first if the change is large or shifts the public API.
